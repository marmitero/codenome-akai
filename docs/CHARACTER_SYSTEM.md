# CHARACTER SYSTEM
Heróis = entidades próprias (colecionáveis/comerciáveis no futuro). Instância: id, defId, name,
level, xp, stars, equipment. Stats = base + growth×(lvl-1) + soma de equipamentos (state.heroStats).
4 iniciais distintos: Ferro(Guerreiro), Aldric(Guardião), Lyra(Duelista), Vesper(Ceifador).
Escolha inicial: 1 dos 4; demais = aquisição futura (P-09). Sem limite de personagens possuídos (§12).
